About

VID GIS Converter reads Shapefile packages entirely inside your browser using the File API. Nothing is uploaded anywhere — files are parsed, validated and converted locally, and everything is discarded when you close or refresh the tab.

No data loss policy

  • Original files are never modified or overwritten.
  • No field, record, or geometry is silently dropped.
  • Leading zeros and text-formatted IDs are preserved exactly as stored in the DBF.
  • Encoding is read from the .cpg file when present, otherwise it falls back to Windows-1252 / UTF-8.
  • Coordinates are never reprojected — the original CRS from the .prj file is reported, not altered.

Supported geometry types: Point, MultiPoint, PolyLine, Polygon (and their Z variants for coordinates; M/Z values are read but not required for WKT/GeoJSON output). MultiPatch attribute-only export is supported; full 3D geometry export is a future feature.

Large files are parsed in memory — very large shapefiles (over roughly 1 GB) may be limited by your device's available RAM.
