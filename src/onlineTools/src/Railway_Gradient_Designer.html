Railway Gradient Designer

User guide for railway_gradient_v07.py — automated vertical alignment design, no-cut zone protection, interactive profile plotting, and Excel / AutoCAD export.

01

Installation & Launch

Ensure Python 3.9+ is installed on your workstation, then install the required GUI, numerical, and spreadsheet dependencies once:

$ pip install PySide6 matplotlib numpy openpyxl

Launch the desktop application from your terminal (optionally passing a survey file path to load immediately):

$ python railway_gradient_v07.py [optional_survey.csv]
02

Input Survey Format (.csv / .txt / .xlsx)

The tool accepts CSV, TXT, or Excel (.xlsx / .xlsm) files structured in 3 columns matching the standard gradient template. Company chainage must be strictly increasing.

Col A · Railway Chainage Col B · Company Chainage (m) Col C · Existing RL (m) Row Type
496/480.000 0 134.520 Survey data point (every 20 m)
496/492.500 SRJ 50A Marker row (text in Col B, blank RL)
496/500.000 20 134.585 Survey data point
496/515.000 C-2 TTC 1 Curve transition marker row
Marker Detection: Any row containing text in Column B (such as SRJ 50A, TTC 1, or TCC 2) and an empty elevation cell is automatically preserved as a track feature and used to enforce no-cut zones.
03

Step-by-Step Workflow

1

Load Survey Data

Click Open CSV… in the top bar and select your survey file. If an Excel workbook contains multiple sheets, a dialog lets you pick the target sheet (defaulting to MDU - NLL DN).

2

Configure Deviation Limits & No-Cut Zones

Verify G MIN and G MAX (allowed lift/lowering tolerance C - E) and confirm the SRJ / TTC / TCC no-cut zone lengths, then click Calculate.

3

Inspect Table & Interactive Profile Graph

Review calculated gradients (1 in N rounded to whole numbers) in the Table tab, or switch to the Graph tab to zoom (mouse wheel) and pan across the existing vs. proposed rail profile and C - E deviation band.

4

Export Deliverables

Click Export Excel… to generate a multi-sheet workbook (ABSTRACT + MDU - NLL DN) with live Excel formulas, or Export AutoCAD CSV… to export gradient change points for CAD drafting.

04

Settings & Engineering Rules

G MIN / G MAX -0.250 / +0.250 m

Permissible vertical deviation envelope where G = Existing RL (C) - New RL (E). Any point breaching this band is highlighted in orange.

LEVEL Threshold 1 in 10000

Segments whose rounded gradient 1 in N is equal to or flatter than this value are classified and labelled as LEVEL (set to 0 to disable).

SRJ / TTC / TCC Zones 50.0 m zone

Prevents vertical grade changes inside a centred zone around each marker (e.g., 50 m = 25 m before + 25 m after). Cuts are forced before or after the zone.

Whole Transition Lock Optional

Enable Also the whole transition to forbid gradient cuts anywhere between paired markers (TTC1 → TCC1 and TCC2 → TTC2).

05

Export Formats

1. Excel Workbook (*_GRADIENT.xlsx): Contains the ABSTRACT summary table and the full MDU - NLL DN calculation sheet (Columns A–T) driven by live formulas linked to editable settings in cells V2:V4.

2. AutoCAD CSV (*_AUTOCAD.csv): Exports one row per vertical gradient change point (start, every grade break, and end) with columns vid_ch, rw_ch, railLevel, lineType, before, current, and note.
