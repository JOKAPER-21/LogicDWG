Yard Tool

Chainage

VIDCHAINAGERUNNER
vidChainageRunner.lsp

What it does

Places chainage marks (dot + text) along selected polylines at a set increment. Optionally adds a KM arrow symbol block at the end of each polyline.

Setup

  • Optional symbol needs vid_blocks_tools.dwg with the block vid_kmArrow_001 (the default name). If the DWG is not found the run continues without symbols.
  • Everything is drawn on layer 1-CHAINAGE (created automatically).

How to use

  1. Click Chainage > Generate (or type VIDCHAINAGERUNNER).
  2. Select one or more polylines. Each runs separately with the same start value.
  3. In the Chainage Runner dialog choose Forward (value is at the polyline start) or Backward (value is at the end; chainage decreases).
  4. Enter KM / metre as e.g. 21/000, and the Increment in metres (default 100).
  5. Tick Add Symbol if wanted and set Symbol Name, Symbol Height (distance of the symbol from the polyline, default 120) and Direction (Up = left of the polyline, Down = right). Click Ok.
  6. Result: a filled circle (0.3 radius) and MTEXT label (height 2, e.g. 21/100) at each step, with km roll-over. The symbol shows KM 22 on top and (21/999.85M) below.

Notes

  • Select the polyline in the direction of increasing chainage for correct labels.
  • The final message gives the polyline, mark and symbol counts. One Undo reverses the run.

Pros & Cons

Pros

  • Any number of polylines in one run, each with automatic km roll-over.
  • Forward and backward chainage supported.
  • End-of-line KM arrow symbol imported and filled automatically.

Cons

  • The symbol block needs vid_blocks_tools.dwg in place.
  • Mark size and text height are fixed in the code.
  • Wrong pick direction gives reversed labels - re-run with the other direction.
