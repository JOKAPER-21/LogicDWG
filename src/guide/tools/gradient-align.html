Gradient Tool

Gradient Align

VIDGRADIENTALIGN
vidGradientAlign.lsp

What it does

Copies selected blocks into a neat staggered grid - for example to lay gradient blocks out as a sheet. The originals stay where they are; the copies get rotation 0.

Setup

  • No file setup. Works in AutoCAD and Civil 3D. Select INSERT blocks (the gradient blocks).

How to use

  1. Click Gradient > Align (or type VIDGRADIENTALIGN).
  2. Fill the dialog (all fields accept 0; last values are remembered): Horizontal space (45) - X distance between blocks; Vertical space (45) - Y distance; Row count (3) - blocks per column, 0 = no limit; Column count (500) - blocks per row, 0 = no limit; Row offset (5) - X shift for offset rows; Column offset (0) - Y drop per next column; Offset step (2) - offset cycle, 0 = no offset; Direction - Vertical fills down each column, Horizontal fills across each row.
  3. After OK, pick a point (top-left of the layout, where block 1 goes).
  4. Select the blocks to copy. They are ordered left to right (ties top to bottom).
  5. Copies are placed. When Row count x Column count is filled, the next set starts directly below. The message reports blocks copied.

Notes

  • One Undo reverses the whole run.

Pros & Cons

Pros

  • Scattered blocks become a clean staggered plotting sheet in one pass.
  • Full control of spacing, offsets, stagger cycle and fill direction.
  • Non-destructive - the original aligned blocks stay on the track.

Cons

  • Copies get rotation 0 by design - rotation from the track is lost in the sheet.
  • Order follows position (left to right), so arrange the blocks roughly first.
  • Very large selections take a while to copy.
