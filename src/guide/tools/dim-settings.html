Settings

Dim Settings

VIDDIMSETTINGS
vidDimSettings.lsp

What it does

Applies the office dimension standard with one click: text style font, arrow size, text height, text alignment and precision.

Setup

  • The drawing needs a dimension style named Standard and a text style named Standard.

How to use

  1. Click Settings > Dim Settings: Apply (or type VIDDIMSETTINGS). The panel re-opens afterwards.
  2. The text style Standard gets font Arial. The dimension style Standard is updated and saved, then your previous dimension style is restored.
  3. Applied values: arrow size 1.5, text height 1.5, text aligned with the dimension line (inside and outside), primary units precision 0.00, font Arial.

Notes

  • To change values, edit the VIDDim:Settings block at the top of vidDimSettings.lsp.
  • If the text style has a fixed height, a note says dimension text uses that height instead.

Pros & Cons

Pros

  • The whole office standard in one click - no dialog touring.
  • Your previous dimension style is restored afterwards.
  • Values are editable in one clearly-marked block at the top of the LSP.

Cons

  • Only the style named Standard is touched - other styles keep their settings.
  • Fixed-height text styles override the dimension text height.
