QC

Block Layer

VIDBLOCKLAYER
vidBlockLayer.lsp

What it does

Moves selected objects - and everything inside any selected block, including blocks nested inside that block - to one target layer.

Setup

  • No setup. Works in AutoCAD and Civil 3D.
  • The target layer must already exist in the drawing.

How to use

  1. Click QC > Block Layer: Change (or type VIDBLOCKLAYER).
  2. In the Block Layer dialog pick the target layer from the drop-down list (all drawing layers, xref layers excluded) and tick or untick Include blocks nested inside the selected blocks. Click OK.
  3. Select any objects. Plain objects are re-layered directly.
  4. For every block in the selection, its attributes and everything inside its definition are moved to the target layer; with the nested option on, blocks inside the block are followed to every level (each definition is processed once - loops are safe).
  5. The report shows objects moved, block-content objects moved and definitions processed. The drawing is regenerated; one Undo reverses the run.

Notes

  • A block definition is shared - every other insert of the same block in the drawing changes too.
  • Objects on locked layers are skipped and counted, not fatal.

Pros & Cons

Pros

  • Fixes block layer chaos in one go - attributes and deeply nested content included.
  • Live drop-down of the drawing's layers - no typing of layer names.
  • Loop-safe recursion and a clear count report.

Cons

  • Changing a shared definition re-layers every insert of that block drawing-wide.
  • Xref content is not touched.
  • The target layer must exist - it is not created for you.
