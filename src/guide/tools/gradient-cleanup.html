Gradient Tool

Gradient Clean Up

VIDGRADIENTCLEANUP
vidGradientCleanup.lsp

What it does

Bursts gradient blocks so the attributes become plain MTEXT, ready for plotting or sending as basic geometry.

Setup

  • No setup. Works in AutoCAD and Civil 3D. Does not need Express Tools.

How to use

  1. Click Gradient > Clean up (or type VIDGRADIENTCLEANUP).
  2. Select the gradient block(s).
  3. Each block is exploded (burst). Every visible attribute becomes text, and all text from the burst is converted to MTEXT, keeping position, height, rotation, style, layer, colour and justification.
  4. The command runs silently with no report. Undo reverses it.

Notes

  • This cannot be re-edited as a block afterwards - keep a copy of the drawing.
  • To limit it to blocks named G_NEW_FINAL, set VGC-OnlyGradient to T in the LSP.

Pros & Cons

Pros

  • Plot-ready basic geometry without Express Tools (no BURST dependency).
  • Every formatting detail of the attributes is preserved as MTEXT.
  • Any number of blocks in one selection.

Cons

  • One-way operation - the result is no longer a block.
  • No confirmation or report; check the result before saving.
