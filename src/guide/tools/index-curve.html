Gradient Index Plan

Index Curve

VIDINDEXCURVE
vidIndexCurve.lsp

What it does

Draws the schematic track geometry line for the index plan from a CSV: straight sections stay straight, curves bulge down for left-hand and up for right-hand, with a radius / degree label at every curve.

Setup

  • CSV header: segment_types,vid_ch,lhs_rhs,degree (header row required). Columns are found by header name; if a name is missing, column order 1,2,3,4 is used. A ready example is vidIndexCurve_template.csv.
  • Transition rows mark the segment boundaries (chainage in metres). Curve rows carry the direction (LH / RH) and the degree; a curve row must fall between two transitions to be used.

How to use

  1. Click Gradient Index Plan > Index Curve: Generate (or type VIDINDEXCURVE).
  2. Select the Track Geometry CSV file.
  3. In the VID Index Curve dialog enter the horizontal scale - 1 KM (1000 m) = 20 m (default, taken from the Index Gradient value when already used).
  4. Pick the insertion point (chainage 0 of the plot).
  5. The geometry line is drawn on the picked point's Y, with the curve labels 5 m below it: radius in metres (1750 / degree) over the degree, rotated to read from the bottom.

Notes

  • Layers: 1-VIC_Rail_Track (magenta) and 1-VIC_Rail_Text (cyan) - created and colour-set automatically.
  • The curve bulge is symbolic: sagitta = chord / 2 capped at 3.6 drawing units, so all curves stay readable at any scale.

Pros & Cons

Pros

  • The whole curve diagram of a section from one CSV - aligned with the Index Gradient by sharing the same default scale.
  • LH / RH direction and radius are derived automatically from the degree.
  • Very tolerant of long files - hundreds of transitions are fine.

Cons

  • Symbolic bulge, not true curve geometry - do not scale off it.
  • Needs at least two Transition rows; curves outside transitions are not found.
  • Labels all sit 5 m below the line at a fixed size.
