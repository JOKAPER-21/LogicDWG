Gradient Index Plan

Index Gradient

VIDINDEXGRADIENT
vidIndexGradient.lsp

What it does

Draws a complete schematic gradient index plan from a CSV: kilometre scale bar with index numbers and ticks, station posts with rail levels, the gradient profile line and the rise/fall text - with independent horizontal and vertical scales.

Setup

  • CSV header: vid_ch,cal_rail_level,rise_fall. Columns are found by header name; if a name is missing, column order 1,2,3 is used. A ready example is vidIndexGradient_template.csv.
  • Rows with an empty chainage, rail level or rise/fall cell are skipped with a warning on the command line.

How to use

  1. Click Gradient Index Plan > Index Gradient: Generate (or type VIDINDEXGRADIENT).
  2. Select the CSV file.
  3. In the VID Index Gradient dialog enter the scales: Horizontal - 1 KM (1000 m) = 20 m (default), and Vertical - 1 KM (1000 m) = 1000 m (default, i.e. no vertical exaggeration; raise it to exaggerate).
  4. Pick the insertion point - chainage 0 of the plan.
  5. Above the picked point the tool draws: index numbers 0,1,2... with a 3 m tick every kilometre, a 2.5 m scale bar of alternating filled/empty half-kilometre boxes (the block is exactly 8 m high), then per station a post with the rail level text (rotated) and the level line up to the scaled rail level, the gradient profile line through the tops, and the rise/fall text of each section between its stations.

Notes

  • Layers: 1-VIG_VID_CH_SCALE_BAR (green), 1-VIG_VID_RAIL_LEVEL (red), 1-VIG_VID_RISE_FALL (yellow) - created and colour-set automatically.
  • Scaling rule for both axes: drawn value = original x scale / 1000. 1000 = no change, less = reduce, more = enlarge.
  • The last used scales are remembered (and shared as the default with Index Curve).

Pros & Cons

Pros

  • A full index gradient sheet - scale bar, levels, profile and grades - from one CSV.
  • Independent horizontal and vertical exaggeration for any paper size.
  • Fixed layer / colour standard keeps every sheet identical.
  • Columns matched by header name, so extra columns do not break it.

Cons

  • Schematic output - it draws from the picked point, not at real-world coordinates.
  • Empty cells silently drop the row (watch the skipped-row warnings).
  • No title block or border - add the sheet frame yourself.
