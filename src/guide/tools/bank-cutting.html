Yard Tool

Bank Cutting

VIDBANKCUTTING
vidBankCutting.lsp

What it does

Places a bank / cutting symbol from two level texts and one click. The height difference between the FT/BE value and the TOE/GL value sets the symbol height text, and the perpendicular distance to the track sets the distance text. Blocks are imported from vid_blocks_tools.dwg (bank_cutting_up, bank_cutting_dn and the _lg variants).

Setup

  • vid_blocks_tools.dwg must contain the blocks bank_cutting_up / bank_cutting_dn / bank_cutting_up_lg / bank_cutting_dn_lg. The DWG is searched next to the LSP, on the support paths and in the registry path remembered from the last run; otherwise you are asked once.
  • The two level values must exist as TEXT or MTEXT in the drawing (e.g. FT/BE and TOE/GL annotations).

How to use

  1. Click Bank Cutting > Generate (or type VIDBANKCUTTING).
  2. Select the FT or BE value text, then the TOE or GL value text. The height difference is computed (within +/-0.3 it becomes the LG - level ground - symbol).
  3. Pick a point for the distance measurement (usually the toe position).
  4. Select the Track - the perpendicular distance from the picked point to the track is measured (2D).
  5. Choose the direction UP / DN. If the height difference is negative the direction is reversed automatically.
  6. The matching block is inserted at the TOE/GL text position, exploded, and its texts are filled: H-<height difference> and D-<distance> (the D text is removed for LG).

Notes

  • The block path is remembered in the registry (HKCU\Software\VID\Tools) after the first run.
  • Works under any UCS - the rotation is converted from WCS automatically.
  • Object snaps are suspended during the internal picks and restored afterwards.

Pros & Cons

Pros

  • Two text picks + one click produce a finished bank symbol with correct H and D values.
  • Automatic UP/DN reversal on negative differences and LG handling near level ground.
  • Blocks are imported once from the DWG and remembered.

Cons

  • Fully interactive - one symbol per run, no batch mode.
  • The block is exploded to fill the texts, so it is plain geometry afterwards.
  • Both level texts must contain a parseable number (non-numeric text aborts the run).
