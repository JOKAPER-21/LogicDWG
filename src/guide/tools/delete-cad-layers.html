QC

Delete CAD Layers

VIDCADMERGELAYERS
vidCadMergeLayers.lsp

What it does

Merges a fixed list of unwanted CAD / Civil 3D layers into layer 0, which clears them from the drawing. Useful after importing a DWG with many template layers.

Setup

  • No setup. The layer list (A-BLDG, C-ANNO..., C-HYDR..., C-PROP..., V-... and so on) is inside the LSP file - edit VIDCADMERGELAYERS:LayerList to add or remove names.

How to use

  1. Click QC > Delete Cad Layer: Delete (or type VIDCADMERGELAYERS).
  2. Layer 0 becomes current. Layers in the list that exist in the drawing are unlocked and thawed.
  3. One -LAYMRG command merges all of them into 0. Layers not in the drawing are skipped.
  4. The report shows layers merged and layers not found. Your previous current layer is restored.

Notes

  • Objects on those layers move to layer 0 - save a copy first.

Pros & Cons

Pros

  • One click clears a whole set of imported Civil 3D template layers.
  • A single -LAYMRG pass - fast even with dozens of layers.
  • Missing layers are skipped safely and listed in the report.

Cons

  • Destructive for the listed layers - objects are moved to layer 0.
  • Only the hard-coded list is processed; other junk layers stay.
