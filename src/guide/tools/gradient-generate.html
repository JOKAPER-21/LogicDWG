Gradient Tool

Gradient Generate

VIDGRADIENT
vidGradient.lsp + vid_blocks_tools.dwg

What it does

Places a gradient block at each position along a track and fills its attributes from a CSV - chainage, rail level, line, tail slope, head slope and note. The slope arrows rotate automatically from the slope text. This is the CSV format of the current release: vid_ch, rw_ch, railLevel, lineType, before, current, note.

Setup

  • CSV header: vid_ch,rw_ch,railLevel,lineType,before,current,note. A tab-separated file also works (the delimiter is detected from the header). A ready example is vidGradient_template.csv.
  • vid_ch = distance in metres along the selected polyline. The note column may contain commas - everything after column 6 is joined back into the note.
  • vid_blocks_tools.dwg must contain the gradient block (default name vid_gradient_001) with attributes G_POSITION, G_CHAINAGE, G_RAILLEVEL, G_LINE, G_TAIL, G_HEAD, G_NOTE and dynamic properties G_POSITION, G_TAIL_ROT, G_HEAD_ROT.

How to use

  1. Click Gradient > Generate (or type VIDGRADIENT).
  2. Select Rail Track: click the polyline. Its length is printed so you can check it against the CSV.
  3. Select the CSV file.
  4. Enter the block name (Enter = vid_gradient_001) and the Gradient Height (Enter = 80) - the offset of the block to the right of the track.
  5. The block is re-imported from the DWG (replacing any older definition), then one block is inserted per CSV row at its vid_ch position, rotated to the track tangent.
  6. Slope arrows rotate from the before / current text: starting with R = 21 degrees, F = 339 degrees, containing LEVEL = 0.
  7. Rows with a vid_ch outside the polyline length are skipped and listed. The end report shows inserted and skipped counts.

Notes

  • The block is placed at its exact position on the polyline, so the block's G_POSITION dynamic property is zeroed on insert - only the attribute shows the value.
  • The last CSV folder is remembered between runs.

Pros & Cons

Pros

  • A whole gradient sheet is built along the real alignment from one CSV.
  • The new CSV matches the railway gradient table columns directly.
  • Arrows and rotation come from the slope text - no manual rotating.
  • The block definition is refreshed from the DWG on every run.

Cons

  • Requires the exact dynamic block in vid_blocks_tools.dwg - missing attributes are reported but not created.
  • vid_ch must be metres along the selected polyline - picking the wrong track skips rows.
  • No preview: blocks are placed as the CSV is read (Undo reverses the run).
