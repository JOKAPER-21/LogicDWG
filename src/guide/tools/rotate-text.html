Settings

Rotate Text

VIDROTTEXT
vidRotText.lsp

What it does

Rotates any number of TEXT and MTEXT objects by adding an angle to each object's current rotation - the quick fix for labels that ended up upside down after a UCS change. Other object types in the selection are ignored.

Setup

  • No setup. Works in AutoCAD and Civil 3D.

How to use

  1. Click Settings > Rotate Text: Rotate (or type VIDROTTEXT).
  2. Enter the rotation angle to add in degrees (default 180, last value is remembered).
  3. Select the TEXT / MTEXT objects (mixed selection is fine).
  4. The command reports how many were rotated; objects on locked layers are skipped and counted. One Undo reverses the run.

Notes

  • The angle is added to each object's own rotation - relative differences between texts are kept.

Pros & Cons

Pros

  • Repairs hundreds of upside-down labels in one selection.
  • Mixed TEXT and MTEXT handled together; everything else ignored.
  • Remembers the last angle for repeated corrections.

Cons

  • Rotation is about each object's insertion point - justified text can shift position.
  • No layer or style filter - everything selected is rotated.
