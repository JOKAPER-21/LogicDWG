2 · Installation and loading

All tools are AutoLISP files loaded by one loader. You set this up once, then every tool is available from the LogicDWG panel or by typing its command.

  1. Unzip the package. Keep vidLoader.lsp and the tools folder together (the tools folder sits next to the loader).
  2. Recommended: copy both into your Civil 3D support folder, so the result is ...\Support\vid\vidLoader.lsp and ...\Support\vid\tools\. The default folder searched is %APPDATA%\Autodesk\C3D 2026\enu\Support\vid\tools.
  3. Add that folder to Options > Files > Support File Search Path, and to Trusted Paths (TRUSTEDPATHS) so AutoCAD does not block the files.
  4. Auto-load (optional): in APPLOAD > Startup Suite > Contents, add vidLoader.lsp.
  5. Without auto-load: type APPLOAD, pick vidLoader.lsp and click Load (or drag and drop it into the drawing).

After loading

  • After loading, read the command line. Each file is listed as [OK] and the list ends with Loaded : 24 / 25 (or 25 / 25) and LogicDWG is ready. Type VIDLOGICDWG to open.
  • Type VIDLOGICDWG (or LOGICDWG) to open the button panel. Or type any tool command directly (listed on each page).
  • If a file shows [ERROR], the loader retries it form by form and prints the failing line and message - check the tools folder is complete.
  • If vidPublish.lsp is not part of your package the loader prints [MISSING] vidPublish.lsp and the completion warning. All other tools are unaffected.
  • Block DWG lookup: Chainage, Gradient and Bank Cutting find vid_blocks_tools.dwg in the same folder as their LSP, then in the Support\vid\tools folders, Trusted Paths and the drawing folder. Bank Cutting remembers the path in the registry after the first run. If the DWG is not found, the command lists the places it checked.

The Tools

Panel

VIDLOGICDWG
LogicDWG Panel & Map Zone
The panel is the control centre of the package: each button runs one tool.

Yard Tool

VIDDGPSTOSP
Survey Points
Imports a DGPS CSV and draws every survey point as a POINT plus three MTEXT labels (point name, code, elevation).
VIDLINETOEXPORTLEVEL
Rail Track Export (levels to CSV)
Reads levels along a polyline / 3D polyline and writes a Chainage,Elevation CSV at a fixed interval.
VIDDGPSTOLINE
Rail Track Generate
Turns the DGPS points of each Code into polylines or 3D polylines - one per code.
VIDCHAINAGERUNNER
Chainage
Places chainage marks (dot + text) along selected polylines at a set increment.
VIDDGPSTOOHE
OHE
Reads OHE-type points from a DGPS CSV and draws a small 0.
VIDDGPSTOBOX
Building
Builds one perfect rectangle from the 3 or 4 DGPS points of each Code group (rooms, buildings, sheds, etc.
VIDRWBOUNDARY
Boundary
Labels the distance from a boundary polyline to a rail track, with an optional chainage in the label (@ KM 21/000).
VIDBANKCUTTING
Bank Cutting
Places a bank / cutting symbol from two level texts and one click.
VIDTR
TR Rectangle
Draws a perfect rectangle in three clicks and labels it TR - for traction / technical rooms in the yard.

Gradient Tool

VIDGRADIENT
Gradient Generate
Places a gradient block at each position along a track and fills its attributes from a CSV - chainage, rail level, line, tail slope, head slope and note.
VIDGRADIENTALIGN
Gradient Align
Copies selected blocks into a neat staggered grid - for example to lay gradient blocks out as a sheet.
VIDGRADIENTCLEANUP
Gradient Clean Up
Bursts gradient blocks so the attributes become plain MTEXT, ready for plotting or sending as basic geometry.

Gradient Index Plan

VIDINDEXGRADIENT
Index Gradient
Draws a complete schematic gradient index plan from a CSV: kilometre scale bar with index numbers and ticks, station posts with rail levels, the gradient profile line and the rise/fall text - with independent horizontal and vertical scales.
VIDINDEXCURVE
Index Curve
Draws the schematic track geometry line for the index plan from a CSV: straight sections stay straight, curves bulge down for left-hand and up for right-hand, with a radius / degree label at every curve.

QC

VIDCADMERGELAYERS
Delete CAD Layers
Merges a fixed list of unwanted CAD / Civil 3D layers into layer 0, which clears them from the drawing.
VIDCADOPTIMIZE
Purge and Audit
One-command drawing optimizer with no dialogs and no questions - every prompt is answered by the code.
VIDBLOCKLAYER
Block Layer
Moves selected objects - and everything inside any selected block, including blocks nested inside that block - to one target layer.

Settings

VIDDIMSETTINGS
Dim Settings
Applies the office dimension standard with one click: text style font, arrow size, text height, text alignment and precision.
VIDDIMMTOFT
Convert Dim Unit (m to ft)
Changes the text of selected aligned or linear dimensions from metres to feet and inches, e.
VIDROTTEXT
Rotate Text
Rotates any number of TEXT and MTEXT objects by adding an angle to each object's current rotation - the quick fix for labels that ended up upside down after a UCS change.

Extras

VIDSURVEYSETTINGS
Survey Settings
Restyles survey annotations in one dialog: text height of TEXT/MTEXT on chosen layers, plus the point marker style (all 20 PDMODE shapes) and point size for the drawing's survey points.
VIDLOGICDWGONLINETOOLS
LogicDWG Online Tools
Opens the LogicDWG online homepage in the default browser - the web companion of this toolset.

Troubleshooting

ProblemWhat to do
Command not foundRun vidLoader.lsp again (APPLOAD) and read the [OK] / [ERROR] list.
Tools folder not foundPut the tools folder next to vidLoader.lsp, or pick logicDwg.lsp when asked.
[MISSING] vidPublish.lsp or vid_railway.cuixExpected when they are not part of your package - all documented tools still work; the cuix only adds the ribbon menu.
Required headers missingCheck the CSV header names against the CSV formats table. DGPS tools accept a full instrument export.
vid_blocks_tools.dwg not foundKeep it in the tools folder. Add the folder to the Support File Search Path and Trusted Paths.
Block imported but attributes emptyCheck the block has the expected attribute tags (see Gradient Generate and Chainage).
Gradient rows skippedvid_ch is longer than the selected polyline - select the right track, or check the printed polyline length against the CSV.
OHE finds no tracksDraw tracks on layer 1-track first, or choose Select at the prompt.
Wrong map locationSet the correct Map Zone (43 or 44) before generating from DGPS data.
LogicDWG did not load completelyRead which file failed in the load list - the loader prints the failing form and message.
