SECTION 01

Installation and loading

All tools are AutoLISP files loaded by one loader. You set this up once, then every tool is available from the LogicDWG panel or by typing its command.

What is in the package

File / folderPurpose
vidLoader.lspLoads every tool file, loads the ribbon menu (vid_railway.cuix) when found, and prints a status list ([OK] / [ERROR] / [MISSING]).
tools\logicDwg.lsp + logicDwg.dclThe main button panel (command VIDLOGICDWG). The .dcl must stay in the same folder as the .lsp.
tools\*.lspOne file per tool (24 tool files in this package; the loader also looks for vidPublish.lsp).
tools\vid_blocks_tools.dwgBlock library. Needed by Chainage (vid_kmArrow_001), Gradient Generate (vid_gradient_001) and Bank Cutting (bank_cutting_up / _dn / _up_lg / _dn_lg).
tools\*_template.csvReady examples for the CSV tools (Survey Points, Rail Track, OHE, Building, Gradient, Index Gradient, Index Curve).
cui\vid_railway.cuix (optional)Ribbon / menu file. The loader searches beside the loader, beside the tools folder and on the support path. If it is not part of your package you will see [MISSING] vid_railway.cuix - the tools still work.

Setup

  1. Unzip the package. Keep vidLoader.lsp and the tools folder together (the tools folder sits next to the loader).
  2. Recommended: copy both into your Civil 3D support folder, so the result is ...\Support\vid\vidLoader.lsp and ...\Support\vid\tools\. The default folder searched is %APPDATA%\Autodesk\C3D 2026\enu\Support\vid\tools.
  3. Add that folder to Options > Files > Support File Search Path, and to Trusted Paths (TRUSTEDPATHS) so AutoCAD does not block the files.
  4. Auto-load (optional): in APPLOAD > Startup Suite > Contents, add vidLoader.lsp.
  5. Without auto-load: type APPLOAD, pick vidLoader.lsp and click Load (or drag and drop it into the drawing).

After loading

  • After loading, read the command line. Each file is listed as [OK] and the list ends with Loaded : 24 / 25 (or 25 / 25) and LogicDWG is ready. Type VIDLOGICDWG to open.
  • Type VIDLOGICDWG (or LOGICDWG) to open the button panel. Or type any tool command directly (listed on each page).
  • If a file shows [ERROR], the loader retries it form by form and prints the failing line and message - check the tools folder is complete.
  • If vidPublish.lsp is not part of your package the loader prints [MISSING] vidPublish.lsp and the completion warning. All other tools are unaffected.
  • Block DWG lookup: Chainage, Gradient and Bank Cutting find vid_blocks_tools.dwg in the same folder as their LSP, then in the Support\vid\tools folders, Trusted Paths and the drawing folder. Bank Cutting remembers the path in the registry after the first run. If the DWG is not found, the command lists the places it checked.

Suggested workflow

StageTools
01Load the tools and set the Map ZoneAPPLOAD vidLoader.lsp, then Map Zone 43 / 44 so everything lands on the map.
02Generate from the DGPS CSVSurvey Points, Rail Track Generate, OHE and Building from the DGPS export.
03Chainage and annotationChainage on the track polylines, then Boundary, Bank Cutting and TR as needed.
04Levels and gradient sheetRail Track Export to make the level CSV, fill the slope columns, then Gradient Generate, Align and Clean Up.

SECTION 02

LogicDWG Panel & Map Zone

Panel
VIDLOGICDWGLOGICDWGVIDMAPZONE
logicDwg.lsp / logicDwg.dcl / vidMapZone.lsp

What it does

The panel is the control centre of the package: each button runs one tool. The Map Zone buttons set the coordinate system and switch the online map on or off. VIDMAPZONE is the same Map Zone as a small stand-alone dialog.

Setup

  • Load the tools (see Installation). No other setup.
  • logicDwg.dcl must stay in the same folder as logicDwg.lsp.

How to use

  1. Type VIDLOGICDWG. The panel opens.
  2. Set the map zone first if you need the online map: click 43 or 44. In Civil 3D / Map 3D the coordinate system UTM84-43N / UTM84-44N is assigned automatically and GeoMap Hybrid is switched on. In plain AutoCAD, set the geographic location when prompted.
  3. Click the button for the tool you want. The panel closes and the tool starts. Only Dim Settings re-opens the panel afterwards.
  4. VIDMAPZONE opens the small MapZone dialog directly (43 / 44 / Off). Off switches GeoMap off.

Notes

  • Panel layout - left column: Yard Tool (Survey Points, Rail Track Export/Generate, Chainage, Ohe, Building, Boundary, Bank Cutting, TR) and Settings (Dim Settings, Convert Dal Unit, Rotate Text).
  • Right column: Map Zone (43 / 44 / Off), Gradient Tool (Generate / Align / Clean Up), Gradient Index Plan (Index Gradient / Index Curve) and QC (Delete Cad Layer, Purge and Audit, Block Layer).
  • Buttons load their tool file on demand if it is not loaded yet, so the panel also works as a repair shortcut.

Pros & cons

Pros

  • One remembered entry point for all 21 panel commands.
  • Map Zone sets coordinate system and aerial map in a single click.
  • Buttons auto-load a missing tool file instead of failing.

Cons

  • The .dcl file must travel with the .lsp - copying only logicDwg.lsp breaks the panel.
  • Map Zone needs Civil 3D / Map 3D for automatic coordinate-system assignment; plain AutoCAD needs the geographic location set manually.
SECTION 03

Survey Points

Yard Tool
VIDDGPSTOSP
vidDgpsToSp.lsp

What it does

Imports a DGPS CSV and draws every survey point as a POINT plus three MTEXT labels (point name, code, elevation). The point display style is set while the points are made (PDMODE 35 - X inside a circle, PDSIZE 0.8 absolute units) so the plot is readable immediately.

Setup

  • CSV with columns: Point Name, Code, Northing, Easting, Elevation. Optional: Local Time. Header names are not case sensitive; a full DGPS instrument export works as-is.
  • Set the drawing to the right UTM zone first (Map Zone 43 / 44) so the points land on the map.
  • Label text height is 0.5 drawing units.

How to use

  1. Click Survey points > Generate (or type VIDDGPSTOSP) and select the DGPS CSV.
  2. In the Survey Point Layer dialog choose the layering: Custom Layer (all points on one layer you type, default 1-SURVEY), CSV Each Code (one layer per code, named sp_<CODE>) or CSV Point Name / Code / Elevation (labels split over sp_POINT NAME / sp_CODE / sp_ELEVATION, the marker on sp_POINT). Click OK.
  3. The command line prints a summary and the first records. Rows with a blank name or non-numeric Northing / Easting / Elevation are skipped.
  4. Result: for each valid row a POINT at (Easting, Northing, Elevation) with MTEXT for name, code and elevation. The end report says the record integrity when the counts match.

Notes

  • The CSV reader handles BOM, UTF-8/UTF-16, quoted fields with commas and LF/CRLF/CR line endings.
  • Layer names are cleaned (spaces and special characters become _) and new layers are created automatically.
  • PDMODE / PDSIZE are drawing-wide and are kept after the run so the points stay visible in the survey style (set DGPS-SP-RestoreStyle to T in the LSP to restore the previous style instead).

Pros & cons

Pros

  • A full labelled survey plot from one CSV in seconds.
  • Three layering schemes, from one layer to fully split label layers.
  • Robust CSV reading - encoding, quotes and line endings never stop the import.
  • Point style is set for you, so markers are visible without extra setup.

Cons

  • PDMODE / PDSIZE are drawing-wide - other point objects in the drawing change appearance too.
  • Text height (0.5) is fixed in the LSP if you need another size.
  • Points land off-map if the wrong Map Zone is set first.
SECTION 04

Rail Track Export (levels to CSV)

Yard Tool
VIDLINETOEXPORTLEVELEXPORTLEVEL20
vidLineToExportLevel.lsp

What it does

Reads levels along a polyline / 3D polyline and writes a Chainage,Elevation CSV at a fixed interval. This CSV is the level source for the Gradient tools.

Setup

  • The track must be a polyline or 3D polyline; the elevation (Z) is read from the vertices.
  • Save the drawing first. The CSV is written to the drawing folder; if the drawing is unsaved or the folder is not writable, a Save dialog appears.

How to use

  1. Click Rail track > Export (or type VIDLINETOEXPORTLEVEL).
  2. Select the polyline.
  3. In the Export Level dialog enter Start Chainage as km/metre in one box, e.g. 21/000, the Interval (whole metres, default 20) and the Track Type (Up / Down / Loop). Click Ok.
  4. A file is written automatically, named rl_<drawing>_v01_<Up|Down|Loop>.csv. Running again makes v02, v03 and so on, counted separately for each drawing and track type.
  5. A message confirms the file path.

CSV template

Example output CSV (written by the tool)

RequiredChainage (written)Elevation (written)
ChainageElevation
21000.0001730.339
21020.0001730.201
21040.0001730.060
21060.0001729.918
Chainage = (km x 1000 + m) + distance along the polyline. A level is written every Interval metres up to the end of the line.

Notes

  • DYNPROMPT is switched off while the command runs so no floating input label disturbs the picks, and restored afterwards.

Pros & cons

Pros

  • Automatic versioned file names - no overwriting of earlier level files.
  • Levels are sampled at exact chainage positions along the curve, not only at vertices.
  • Feeds the Gradient Generate workflow directly.

Cons

  • Needs a polyline with real Z values - a flat 2D polyline exports zeros.
  • Interval is whole metres only.
  • Writes next to the drawing; unsaved drawings trigger a Save prompt.
SECTION 05

Rail Track Generate

Yard Tool
VIDDGPSTOLINE
vidDgpsToLine.lsp

What it does

Turns the DGPS points of each Code into polylines or 3D polylines - one per code. Hectometre posts (HP) are detected automatically and used to give every track the same direction as the chainage.

Setup

  • CSV columns required: Point Name, Code, Northing, Easting, Elevation. Optional: Local Time.
  • HP rows are found by point name or code, e.g. HP 71/600, HP 71-600, HP 71_600, HP 71 600, HP71/600. At least 2 HP points are needed for the direction step.
  • Set the UTM zone first (Map Zone 43 / 44).

How to use

  1. Click Rail track > Generate (or type VIDDGPSTOLINE) and select the CSV.
  2. Rail Track - Select Layer dialog: choose Polyline or 3D Polyline, then pick the Code(s) from the list. Codes R, R1, R2 ... R<n> are pre-selected.
  3. Set the options: Angle filter +/- (whole degrees, default 5) removes spike vertices. Tick Use Local Time column to join points in time order; leave it off to join nearest points from both ends of the chain.
  4. Click Select Layers. The Layer Options dialog opens: Default layers (pick from the list, e.g. 1-TRACK, 1-OHE, 1-PLATFORM), Custom Layer (type a name) or From CSV (layer 1-TRACK_<Code> per code). Click OK.
  5. The report shows rows, valid, unique codes and the points per code. One polyline is created per code, all aligned to the HP chainage direction. The temporary HP curve and HP layer are removed afterwards.

Notes

  • Last-used options are remembered between runs.
  • Set DGPS-HPKeep to T in the LSP to keep the temporary HP spline for checking.

Pros & cons

Pros

  • HP auto-detection fixes track direction without any manual reversing.
  • Angle filter removes DGPS spike points cleanly.
  • Per-code layers created automatically (From CSV mode).
  • Handles big instrument CSVs with the robust reader.

Cons

  • Direction correction needs at least 2 HP points in the file.
  • Without Local Time, nearest-join can mis-order points on sharp branches.
  • Groups with fewer than 2 points are silently skipped (check the report).
SECTION 06

Chainage

Yard Tool
VIDCHAINAGERUNNER
vidChainageRunner.lsp

What it does

Places chainage marks (dot + text) along selected polylines at a set increment. Optionally adds a KM arrow symbol block at the end of each polyline.

Setup

  • Optional symbol needs vid_blocks_tools.dwg with the block vid_kmArrow_001 (the default name). If the DWG is not found the run continues without symbols.
  • Everything is drawn on layer 1-CHAINAGE (created automatically).

How to use

  1. Click Chainage > Generate (or type VIDCHAINAGERUNNER).
  2. Select one or more polylines. Each runs separately with the same start value.
  3. In the Chainage Runner dialog choose Forward (value is at the polyline start) or Backward (value is at the end; chainage decreases).
  4. Enter KM / metre as e.g. 21/000, and the Increment in metres (default 100).
  5. Tick Add Symbol if wanted and set Symbol Name, Symbol Height (distance of the symbol from the polyline, default 120) and Direction (Up = left of the polyline, Down = right). Click Ok.
  6. Result: a filled circle (0.3 radius) and MTEXT label (height 2, e.g. 21/100) at each step, with km roll-over. The symbol shows KM 22 on top and (21/999.85M) below.

Notes

  • Select the polyline in the direction of increasing chainage for correct labels.
  • The final message gives the polyline, mark and symbol counts. One Undo reverses the run.

Pros & cons

Pros

  • Any number of polylines in one run, each with automatic km roll-over.
  • Forward and backward chainage supported.
  • End-of-line KM arrow symbol imported and filled automatically.

Cons

  • The symbol block needs vid_blocks_tools.dwg in place.
  • Mark size and text height are fixed in the code.
  • Wrong pick direction gives reversed labels - re-run with the other direction.
SECTION 07

OHE

Yard Tool
VIDDGPSTOOHE
vidDgpsToOhe.lsp

What it does

Reads OHE-type points from a DGPS CSV and draws a small 0.3 square beside the nearest track plus a stacked-fraction label, for each mast / portal.

Setup

  • CSV columns required: Code, Northing, Easting. The header can be anywhere near the top (title and blank lines above it are ignored). Alternative header names are accepted: Code / Point Code / Feature Code, Northing / North / N / Y, Easting / East / E / X.
  • Codes must start with OHE, OH, OM or PORTAL. The rest of the code is the identifier, e.g. OH 40/22A. Separators - . and space are converted to /.
  • Track polylines must exist on layer 1-track (draw them with Rail Track Generate first).

How to use

  1. Click Ohe > Generate (or type VIDDGPSTOOHE) and select the CSV.
  2. At the prompt Track polylines [Auto/Select] <Auto> press Enter to use every polyline on 1-track, or type S and select them.
  3. The tool finds the nearest track for each point and builds the square on the side away from the track (left-hand point = left, right-hand = right).
  4. A stacked MTEXT label (e.g. 40 over 22A) is placed on the rectangle edge, rotated to the track direction and kept readable.
  5. Everything goes on layer 1-OHE-CSV. The report lists valid rows, rectangles, texts and failures.

Notes

  • Square size 0.3 and text height 1.5 are set at the top of the LSP if you want to change them.

Pros & cons

Pros

  • Very tolerant CSV reading - header anywhere, several aliases, any common delimiter.
  • Side-aware placement keeps every mast symbol clear of the track.
  • Handles OHE / OH / OM / PORTAL code families in one pass.

Cons

  • Needs the tracks drawn on layer 1-track first (or use Select at the prompt).
  • Only OHE-family codes are used - other rows in the CSV are ignored.
  • Symbol and text sizes are hard-coded at the top of the LSP.
SECTION 08

Building

Yard Tool
VIDDGPSTOBOX
VidDgpsToBox.lsp

What it does

Builds one perfect rectangle from the 3 or 4 DGPS points of each Code group (rooms, buildings, sheds, etc.) and labels it with the code.

Setup

  • CSV columns required: Code, Northing, Easting, Elevation. Optional: Local Time (sorts points inside a group).
  • Optional: track polylines. You are asked to select them first; the label is rotated to follow the nearest one. Press Enter to skip - labels then follow the box direction.

How to use

  1. Click Building > Generate (or type VIDDGPSTOBOX).
  2. Select the track polyline(s) used for label rotation (any layer), or press Enter to skip.
  3. Select the CSV. Rows are grouped by the Code column (case-insensitive: Gate and GATE are one group) and sorted by Local Time.
  4. Dgps To Box - Select Layers: tick the Code groups to build (room, building, toilet, station, shed, office, quarter, shop and similar names are pre-selected). Click Select Layers.
  5. Layer Options: choose a default layer (e.g. 1-BUILDINGS), From CSV (1-TRACK_<Code>) or a custom name. Click OK.
  6. Nearby points are clustered: 4 nearby points with the 4th close to the computed corner give a rectangle from 4 points, otherwise 3 points are used (point 1 to 2 sets direction and length, point 3 sets the width). A group with more points is split into further clusters.
  7. An MTEXT label (height 0.5) is placed at the centre. The report gives rectangles created, failed and points not used.

OptionalLocal Time

  • Cluster distance (VDB-ClusterDist) and corner tolerance (VDB-DevTol) are set at the top of the LSP.

Pros & cons

Pros

  • Perfect rectangles from rough 3-4 point field surveys - no manual squaring.
  • Time sorting + clustering handles re-measured and mixed points automatically.
  • Labels follow the track direction for a clean drawing.

Cons

  • Groups with fewer than 3 points cannot make a rectangle and are skipped.
  • Without Local Time the point order (and therefore the rectangle direction) follows the file order.
  • Clustering tolerances are fixed in the LSP - very large buildings may need them raised.
SECTION 09

Boundary

Yard Tool
VIDRWBOUNDARY
vidRwBoundary.lsp

What it does

Labels the distance from a boundary polyline to a rail track, with an optional chainage in the label (@ KM 21/000). Labels can be placed at every boundary vertex or at a fixed spacing along the boundary, always on the side inside the boundary.

Setup

  • A closed or open boundary polyline (LWPOLYLINE or POLYLINE, 2D or 3D) and a track (line / polyline / curve).
  • Nothing else - the layer 1-boundary and the text style ARIAL_TXT are created automatically.

How to use

  1. Click Boundary > Generate (or type VIDRWBOUNDARY).
  2. In the VID RW Boundary dialog choose the label position: Vertex (at boundary vertices, skipping vertices closer than 2 m) or Distance (a label every Distance between labels, default 40 m).
  3. Tick @KM/METER and enter the starting KM (e.g. 21/000) if the chainage should be shown in the label.
  4. Click Select Boundary and pick the boundary polyline, then Select Track and pick the track. The dialog shows what is selected.
  5. Click Generate. Each label shows the perpendicular distance in metres (e.g. 12.35m) and, if ticked, the chainage at that point (@ KM 21/040).
  6. The command line reports how many labels were added. One Undo reverses the run.

Notes

  • Text height 1.25, placed 2.5 m inside the boundary, rotated to the track direction and kept readable along the run.
  • Labels are only made where the perpendicular foot falls on the track (not past its ends).
  • Distances are 2D (plan) distances.

Pros & cons

Pros

  • Two placement modes - vertices for corners, fixed spacing for long straight fences.
  • Distance and chainage combined in one label, automatically computed along the track.
  • Dialog with validation: nothing is drawn until both objects are picked.
  • Labels always sit inside the boundary and read along the track.

Cons

  • Track ends are excluded - no label where the perpendicular falls beyond them.
  • Text height and offset are fixed in the code.
  • 2D distances only - level differences are ignored.
SECTION 10

Bank Cutting

Yard Tool
VIDBANKCUTTING
vidBankCutting.lsp

What it does

Places a bank / cutting symbol from two level texts and one click. The height difference between the FT/BE value and the TOE/GL value sets the symbol height text, and the perpendicular distance to the track sets the distance text. Blocks are imported from vid_blocks_tools.dwg (bank_cutting_up, bank_cutting_dn and the _lg variants).

Setup

  • vid_blocks_tools.dwg must contain the blocks bank_cutting_up / bank_cutting_dn / bank_cutting_up_lg / bank_cutting_dn_lg. The DWG is searched next to the LSP, on the support paths and in the registry path remembered from the last run; otherwise you are asked once.
  • The two level values must exist as TEXT or MTEXT in the drawing (e.g. FT/BE and TOE/GL annotations).

How to use

  1. Click Bank Cutting > Generate (or type VIDBANKCUTTING).
  2. Select the FT or BE value text, then the TOE or GL value text. The height difference is computed (within +/-0.3 it becomes the LG - level ground - symbol).
  3. Pick a point for the distance measurement (usually the toe position).
  4. Select the Track - the perpendicular distance from the picked point to the track is measured (2D).
  5. Choose the direction UP / DN. If the height difference is negative the direction is reversed automatically.
  6. The matching block is inserted at the TOE/GL text position, exploded, and its texts are filled: H-<height difference> and D-<distance> (the D text is removed for LG).

Notes

  • The block path is remembered in the registry (HKCU\Software\VID\Tools) after the first run.
  • Works under any UCS - the rotation is converted from WCS automatically.
  • Object snaps are suspended during the internal picks and restored afterwards.

Pros & cons

Pros

  • Two text picks + one click produce a finished bank symbol with correct H and D values.
  • Automatic UP/DN reversal on negative differences and LG handling near level ground.
  • Blocks are imported once from the DWG and remembered.

Cons

  • Fully interactive - one symbol per run, no batch mode.
  • The block is exploded to fill the texts, so it is plain geometry afterwards.
  • Both level texts must contain a parseable number (non-numeric text aborts the run).
SECTION 11

TR Rectangle

Yard Tool
VIDTR
vidTr.lsp

What it does

Draws a perfect rectangle in three clicks and labels it TR - for traction / technical rooms in the yard. Point 1 is the start corner, point 2 sets direction and length, point 3 sets the height side. A centred MTEXT label TR is added, rotated 180 degrees to the rectangle.

Setup

  • No setup. Layer 1-TR is created automatically (colour 7) and your current layer is restored afterwards.

How to use

  1. Click TR > Generate (or type VIDTR).
  2. Click point 1 (start corner).
  3. Click point 2 (direction + length).
  4. Click point 3 (height side) - the rectangle closes perfectly square to points 1-2.
  5. The TR label is placed at the centre. Press Esc at any pick to cancel cleanly.

Pros & cons

Pros

  • Fastest possible labelled rectangle - three clicks, always orthogonal.
  • Own layer created and previous layer restored automatically.

Cons

  • Sizes come from mouse picks only - no typed dimensions.
  • The label is fixed to TR with height 2.0.
  • 2D only - elevation is ignored.
SECTION 12

Gradient Generate

Gradient Tool
VIDGRADIENT
vidGradient.lsp + vid_blocks_tools.dwg

What it does

Places a gradient block at each position along a track and fills its attributes from a CSV - chainage, rail level, line, tail slope, head slope and note. The slope arrows rotate automatically from the slope text. This is the CSV format of the current release: vid_ch, rw_ch, railLevel, lineType, before, current, note.

Setup

  • CSV header: vid_ch,rw_ch,railLevel,lineType,before,current,note. A tab-separated file also works (the delimiter is detected from the header). A ready example is vidGradient_template.csv.
  • vid_ch = distance in metres along the selected polyline. The note column may contain commas - everything after column 6 is joined back into the note.
  • vid_blocks_tools.dwg must contain the gradient block (default name vid_gradient_001) with attributes G_POSITION, G_CHAINAGE, G_RAILLEVEL, G_LINE, G_TAIL, G_HEAD, G_NOTE and dynamic properties G_POSITION, G_TAIL_ROT, G_HEAD_ROT.

How to use

  1. Click Gradient > Generate (or type VIDGRADIENT).
